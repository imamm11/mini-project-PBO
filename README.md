# mini-project-PBO
Mini Project Data Mahasiswa
1. Deskripsi
Mini project ini merupakan program sederhana menggunakan bahasa pemrograman Java untuk menginput dan menampilkan data mahasiswa. Program ini dapat menyimpan nama, NIM, dan nilai dari 3 mahasiswa, kemudian menentukan apakah mahasiswa tersebut lulus atau tidak berdasarkan nilai yang diperoleh.

2. Fitur Program
Menginput nama mahasiswa.
Menginput NIM mahasiswa.
Menginput nilai mahasiswa.
Menampilkan seluruh data mahasiswa.
Menentukan status kelulusan mahasiswa.
3. Konsep Java yang Digunakan
Class dan Object: Class Mahasiswa digunakan untuk menyimpan data dan fungsi mahasiswa.
Array: Digunakan untuk menyimpan 3 objek mahasiswa dalam satu variabel.
Perulangan For: Digunakan untuk menginput dan menampilkan data mahasiswa.
Percabangan If-Else: Digunakan untuk menentukan status kelulusan.
Scanner: Digunakan untuk menerima input dari pengguna.
Method: tampilkanData() untuk menampilkan data dan cekKelulusan() untuk menentukan status kelulusan.
4. Aturan Kelulusan
Program menggunakan aturan berikut:

Nilai ≥ 60: Lulus.
Nilai < 60: Tidak Lulus.
5. Cara Menjalankan Program
Pastikan Java sudah terpasang di komputer.

Simpan kode program dengan nama Main.java.

Buka terminal pada folder tempat file disimpan.

Compile program dengan perintah:

javac Main.java
Jalankan program dengan perintah:

java Main
Masukkan nama, NIM, dan nilai untuk 3 mahasiswa sesuai petunjuk yang muncul.

7. Kesimpulan
Mini project ini dibuat untuk memahami penggunaan class, object, array, method, perulangan, dan percabangan dalam Java. Program ini juga membantu memahami cara menerima input, mengolah data, dan menampilkan hasil berdasarkan kondisi tertentu.
